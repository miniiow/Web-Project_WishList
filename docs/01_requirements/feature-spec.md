## 2. 사용자 기능

|기능 ID|기능명|사전 조건|입력|처리 과정|정상 결과|예외 처리|
|--|--|--|--|--|--|--|
|F-01|회원가입|로그인하지 않은 상태이다.|회원 아이디, 비밀번호, 회원 이름, 이메일 주소(모두 필수)|1. 모든 항목이 입력되었는지 확인한다(Sec-005).<br>2. 회원 아이디가 영문 대/소문자, 숫자로 20자 이하인지 확인한다.<br>3. 비밀번호가 규칙에 맞는지 확인한다. 영문, 숫자, 특수문자 중 2종류 이상을 조합하면 10자 이상, 3종류 이상을 조합하면 8자 이상이어야 하고, 연속된 숫자는 사용할 수 없다. 특수문자는 `! @ # $ % ^ & *`만 사용할 수 있다.<br>4. 이메일 주소에 @가 들어 있는지 확인한다.<br>5. 이미 사용 중인 회원 아이디인지 확인한다.<br>6. 비밀번호를 해시한다(Sec-004).<br>7. 회원 정보를 저장한다(Data-001).|가입 완료를 안내하고 로그인할 수 있다(UI-002).|- 입력하지 않은 항목이 있으면 어떤 항목인지 안내하고 저장하지 않는다.<br>- 아이디 형식이 맞지 않거나 이미 사용 중인 아이디이면 안내하고 저장하지 않는다.<br>- 비밀번호가 규칙에 맞지 않으면 안내하고 저장하지 않는다.<br>- 이메일 주소에 @가 없으면 안내하고 저장하지 않는다.|
|F-02|로그인|로그인하지 않은 상태이다. 가입된 회원 또는 관리자 계정이 있다.|회원 아이디, 비밀번호|1. 아이디와 비밀번호가 입력되었는지 확인한다.<br>2. 입력한 비밀번호를 해시하여 저장된 값과 비교한다(Sec-004).<br>3. 일치하면 로그인 상태로 만든다.|로그인되어 회원은 회원 메뉴(위시리스트 메뉴)로, 관리자는 관리자 메뉴로 이동한다. 회원은 위시리스트와 내 정보 화면을, 관리자는 회원 관리 기능을 사용할 수 있다.|- 아이디나 비밀번호가 비어 있으면 안내한다.<br>- 아이디 또는 비밀번호가 맞지 않으면 로그인 실패를 안내한다.|
|F-03|로그아웃|로그인한 상태이다.|로그아웃 요청|1. 로그인 상태를 해제한다.|로그아웃되어 위시리스트와 내 정보 화면에 접근할 수 없다(Sec-002).|- 이미 로그아웃된 상태이면 로그인 화면으로 안내한다.|
|F-04|내 정보 조회|회원으로 로그인한 상태이다.|조회 요청|1. 로그인한 회원의 정보를 조회한다.<br>2. 비밀번호는 표시하지 않는다.|회원 아이디, 회원 이름, 이메일 주소가 표시된다.|- 로그인하지 않았으면 로그인 화면으로 안내한다(Sec-002).|
|F-05|내 정보 수정|회원으로 로그인한 상태이다.|회원 이름, 이메일 주소. 비밀번호를 바꿀 때는 기존 비밀번호와 새 비밀번호를 함께 입력한다.|1. 필수 항목이 입력되었는지 확인한다(Sec-005).<br>2. 이메일 주소에 @가 들어 있는지 확인한다.<br>3. 비밀번호를 바꾸는 경우 기존 비밀번호를 해시하여 저장된 값과 비교한다.<br>4. 일치하면 새 비밀번호가 회원가입의 비밀번호 규칙에 맞는지 확인하고 해시하여 저장한다(Sec-004).<br>5. 변경한 정보를 저장한다. 비밀번호를 바꾸지 않으면 기존 비밀번호가 유지된다.|수정 완료를 안내하고 변경된 정보가 반영된다(UI-002).|- 회원 아이디는 수정할 수 없다.<br>- 기존 비밀번호가 맞지 않으면 비밀번호를 변경하지 않고 안내한다.<br>- 새 비밀번호가 규칙에 맞지 않거나 이메일 주소에 @가 없으면 안내하고 저장하지 않는다.<br>- 필수 항목이 비어 있으면 안내하고 저장하지 않는다.|
|F-06|회원 탈퇴|회원으로 로그인한 상태이다. 관리자 계정은 탈퇴할 수 없다.|탈퇴 요청, 탈퇴 확인 응답(비밀번호는 다시 입력받지 않는다)|1. 한 번 더 탈퇴 여부를 확인한다(UI-003).<br>2. 확인하면 해당 회원의 위시리스트 데이터를 삭제한다.<br>3. 회원 정보를 완전히 삭제한다(Data-003).<br>4. 로그인 상태를 해제한다.|탈퇴 완료를 안내하고 첫 화면으로 이동한다. 삭제된 데이터는 복구할 수 없다.|- 확인 단계에서 취소하면 탈퇴하지 않는다.<br>- 관리자 계정은 탈퇴할 수 없다고 안내한다.|

## 3. 위시관리 기능

|기능 ID|기능명|사전 조건|입력|처리 과정|정상 결과|예외 처리|
|--|--|--|--|--|--|--|
|F-07|물건 등록|회원으로 로그인한 상태이다.|물건 이름, 가격, 우선도('높음 / 보통 / 낮음')는 필수. 쇼핑몰 링크와 이미지 파일(.jpg, .png, .gif)은 선택. 링크는 F-08 사용 시 함께 저장한다.|1. 필수 항목이 입력되었는지 확인한다.<br>2. 이름이 200자 이하인지, 가격이 0원 이상의 숫자인지, 우선도가 정해진 값인지 확인한다(Sec-005). 가격은 출시 예정이나 가격 미정인 물건을 위해 0원도 허용한다.<br>3. 이미지 파일이 있으면 .jpg, .png, .gif 형식인지 확인한다.<br>4. 구매 여부를 '구매안함', 등록일을 현재 시각으로 정한다.<br>5. 로그인한 회원과 연결하여 저장한다(Data-002).|위시리스트에 물건이 추가되고 등록 완료를 안내한다. 기본 정렬에서 가장 위에 보인다(UI-002).|- 필수 항목이 비어 있으면 안내하고 저장하지 않는다.<br>- 이름이 200자를 넘거나, 가격이 0원 미만이거나 숫자가 아니거나, 우선도가 정해진 값이 아니면 안내하고 저장하지 않는다.<br>- 이미지 파일 형식이 .jpg, .png, .gif가 아니면 안내하고 저장하지 않는다.|
|F-08|쇼핑몰 링크 자동 입력|회원으로 로그인한 상태이고 물건 등록 화면이다.|쇼핑몰 링크(네이버, 11번가)|1. 링크가 지원하는 쇼핑몰의 링크인지 확인한다.<br>2. 링크의 상품 페이지에서 이미지, 이름, 가격을 가져와 입력 항목에 채운다.<br>3. 링크는 물건 정보와 함께 저장한다.|이름, 가격, 이미지가 채워진 상태로 등록 화면에 보인다. 회원은 채워진 내용을 확인하고 수정할 수 있으며, 확인한 뒤 등록한다.|- 지원하지 않는 쇼핑몰이거나 링크 형식이 올바르지 않으면 안내하고 직접 입력하게 한다.<br>- 정보를 가져오지 못하면 실패를 안내하고 직접 입력하게 한다(UI-006).<br>- 이미지가 없으면 기본 이미지를 보여 준다(UI-005).|
|F-09|물건 수정|회원으로 로그인한 상태이고, 본인이 등록한 구매안함 상태의 물건이 있다.|수정할 물건, 물건 이름, 가격, 우선도|1. 본인이 등록한 물건인지 확인한다(Sec-001).<br>2. 구매완료 상태인지 확인한다.<br>3. 입력값을 검증한다(Sec-005).<br>4. 변경한 정보를 저장한다.|수정 완료를 안내하고 변경된 내용이 목록과 상세에 반영된다(UI-002).|- 구매완료된 물건이면 수정할 수 없다고 안내한다.<br>- 다른 회원의 물건이거나 없는 물건이면 접근할 수 없다고 안내한다.<br>- 이름이 200자를 넘거나, 가격이 0원 미만이거나 숫자가 아니거나, 우선도가 정해진 값이 아니면 안내하고 저장하지 않는다.|
|F-10|물건 삭제|회원으로 로그인한 상태이고, 본인이 등록한 물건이 있다.|삭제할 물건, 삭제 확인 응답|1. 본인이 등록한 물건인지 확인한다(Sec-001).<br>2. 한 번 더 삭제 여부를 확인한다(UI-003).<br>3. 확인하면 물건을 삭제한다.|삭제 완료를 안내하고 목록에서 사라진다. 구매완료된 물건도 삭제할 수 있다.|- 확인 단계에서 취소하면 삭제하지 않는다.<br>- 다른 회원의 물건이거나 없는 물건이면 접근할 수 없다고 안내한다.|
|F-11|위시리스트 조회|회원으로 로그인한 상태이다.|조회 요청|1. 로그인한 회원이 등록한 물건 중 구매안함 상태인 물건만 조회한다(Sec-001).<br>2. 구매완료한 물건은 목록에서 제외한다.<br>3. 등록일이 최근인 순서로 정렬한다.|물건의 이름, 가격, 우선도가 목록으로 표시된다. 구매완료한 물건은 목록에 보이지 않고 구매완료 탭에서 확인한다.|- 표시할 물건이 없으면 없다고 안내한다(UI-004).<br>- 로그인하지 않았으면 로그인 화면으로 안내한다(Sec-002).|
|F-12|물건 상세 조회|회원으로 로그인한 상태이고, 위시리스트 또는 구매완료 탭에 물건이 있다.|목록에서 선택한 물건|1. 본인이 등록한 물건인지 확인한다(Sec-001).<br>2. 물건의 상세 정보를 조회한다.|물건의 이름, 가격, 우선도, 구매 상태에 더해 이미지와 등록일이 표시된다. 저장된 쇼핑몰 링크가 있으면 함께 표시하고, 링크를 누르면 해당 쇼핑몰 페이지로 이동한다.|- 이미지가 없으면 기본 이미지를 보여 준다(UI-005).<br>- 다른 회원의 물건이거나 없는 물건이면 접근할 수 없다고 안내한다.|
|F-13|우선도순 조회|회원으로 로그인한 상태이다.|우선도순 보기 선택|1. 본인이 등록한 물건 중 구매안함 상태인 물건을 조회한다.<br>2. 우선도가 높은 순서(높음, 보통, 낮음)로 정렬한다.<br>3. 우선도가 같으면 가격이 높은 물건을 위로, 가격도 같으면 먼저 등록한(오래된) 물건을 위로 정렬한다.|우선도가 높은 물건부터 목록으로 표시된다.|- 등록한 물건이 없으면 없다고 안내한다(UI-004).|
|F-14|구매완료 표시|회원으로 로그인한 상태이고, 본인이 등록한 구매안함 상태의 물건이 있다.|구매완료로 표시할 물건|1. 본인이 등록한 물건인지 확인한다(Sec-001).<br>2. 구매 상태를 '구매완료'로 바꾼다.|물건이 위시리스트 목록에서 사라지고 구매완료 탭에 모아진다. 총 필요 금액에서는 제외된다. 구매 날짜는 기록하지 않는다.|- 이미 구매완료이면 안내한다.<br>- 다른 회원의 물건이거나 없는 물건이면 접근할 수 없다고 안내한다.|
|F-15|구매완료 표시 취소|회원으로 로그인한 상태이고, 본인이 등록한 구매완료 상태의 물건이 있다.|취소할 물건|1. 본인이 등록한 물건인지 확인한다(Sec-001).<br>2. 구매 상태를 '구매안함'으로 되돌린다.|물건이 구매완료 탭에서 사라지고 다시 위시리스트 목록에 표시된다. 다시 수정할 수 있고 총 필요 금액에 포함된다.|- 구매안함 상태이면 안내한다.<br>- 다른 회원의 물건이거나 없는 물건이면 접근할 수 없다고 안내한다.|
|F-16|구매완료 목록 조회|회원으로 로그인한 상태이다.|구매완료 탭 선택|1. 본인이 등록한 물건 중 구매완료 상태인 물건만 조회한다.|구매완료한 물건이 구매완료 탭에 목록으로 표시된다.|- 구매완료한 물건이 없으면 없다고 안내한다(UI-004).|
|F-17|총 필요 금액 조회|회원으로 로그인한 상태이다.|총 금액 보기 선택|1. 본인이 등록한 물건 중 구매안함 상태인 물건의 가격을 모두 더한다.<br>2. 구매완료한 물건은 더하지 않는다.|앞으로 결제해야 할 총 금액이 표시된다.|- 구매안함 상태의 물건이 없으면 금액 대신 안내 문구를 표시한다.|

|F-18|회원 목록 조회|관리자로 로그인한 상태이다.|조회 요청|1. 관리자인지 확인한다(Sec-003).<br>2. 가입한 회원을 조회한다. 관리자 계정은 목록에서 제외한다.|회원 아이디, 회원명, 이메일 주소가 목록으로 표시된다. 관리자 계정은 포함되지 않는다.|- 관리자가 아니면 접근할 수 없다고 안내한다.<br>- 조회된 회원이 없으면 없다고 안내한다(UI-004).|
