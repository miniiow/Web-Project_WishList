## 1. 데이터

|데이터|Data-001|회원·위시 정보 저장|회원 정보와 위시리스트 물건 정보를 데이터베이스에 저장한다. 회원 정보는 회원 아이디, 비밀번호, 회원 이름, 이메일 주소로 이루어져 있다. 물건 정보는 물건 이름, 가격, 우선도, 구매 상태, 이미지, 쇼핑몰 링크, 등록일이다. 관리자 계정은 DB를 생성할 때 미리 만들어 둔다.|C1|User-001, User-002, Wish-001, Wish-009|
|데이터|Data-002|회원별 위시리스트 연결|위시리스트 물건은 등록한 회원과 연결하여 저장한다. 회원별로 자신의 물건만 구분하여 조회할 수 있어야 한다.|C1, NEEDS_02|Wish-004, Sec-001|
|데이터|Data-003|탈퇴 시 데이터 삭제|회원이 탈퇴하거나 관리자가 회원을 탈퇴 처리하면 해당 회원의 정보와 위시리스트 데이터를 함께 완전히 삭제한다.|NEEDS_07, NEEDS_09|User-006, Admin-003|

## 2. 보안

|요구사항분류|요구사항 ID|요구사항명|요구사항 상세|근거|관련 요구사항|
|--|--|--|--|--|--|
|보안|Sec-001|본인 위시리스트만 접근|회원은 자신이 등록한 물건만 조회, 수정, 삭제할 수 있다. 다른 회원의 위시리스트에는 접근할 수 없고, 관리자도 회원의 위시리스트를 확인할 수 없다.|NEEDS_02, C1|Wish-002, Wish-003, Wish-004, Admin-002|
|보안|Sec-002|로그인 한 회원만 접근 가능|로그인하지 않은 사용자는 위시리스트와 내 정보 화면에 접근할 수 없다. 접근하려고 하면 로그인 화면으로 안내한다.|NEEDS_02|User-002, User-003|
|보안|Sec-003|관리자 기능 접근 제한|회원 목록 조회, 회원 상세 조회, 회원 강제탈퇴 처리는 관리자만 사용할 수 있다. 일반 회원은 관리자 화면과 기능에 접근할 수 없다.|NEEDS_08, NEEDS_09|Admin-001, Admin-002, Admin-003|
|보안|Sec-004|비밀번호 해시 저장|비밀번호는 원래 값을 저장하지 않고 해시한 값으로 저장한다. 로그인할 때는 입력한 비밀번호를 같은 방식으로 해시하여 저장된 값과 비교한다. 관리자 계정의 비밀번호도 같은 방식으로 저장한다.|NEEDS_02|User-001, User-002, User-005|
|보안|Sec-005|입력값 검증|회원가입 항목(회원 아이디, 비밀번호, 회원 이름, 이메일 주소)과 물건 등록·수정 항목(이름, 가격, 우선도)은 필수 입력을 확인한다. 가격은 숫자 형식인지 확인하고, 우선도는 '높음 / 보통 / 낮음' 중 하나인지 확인한다. 올바르지 않은 값은 저장하지 않는다.|NEEDS_01|User-001, Wish-001, Wish-002|

## 3. 사용성

|요구사항분류|요구사항 ID|요구사항명|요구사항 상세|근거|관련 요구사항|
|--|--|--|--|--|--|
|사용성|UI-001|핵심 기능의 간단한 이용|물건 추가, 위시리스트 확인, 구매완료 처리는 로그인 후 적은 단계로 이용할 수 있다. 화면 배치와 버튼 위치는 이번 단계에서 정하지 않는다.|C2, C3|Wish-001, Wish-004, Wish-006|
|사용성|UI-002|처리 결과 안내|등록, 수정, 삭제, 구매완료 표시, 정보 수정, 탈퇴 등의 처리 결과를 회원이 알 수 있도록 안내한다. 입력 오류가 있으면 어떤 항목이 잘못되었는지 안내한다.|NEEDS_01|Wish-001, Wish-002, Sec-005|
|사용성|UI-003|삭제 전 확인|회원 탈퇴, 관리자의 회원 탈퇴 처리, 물건 삭제처럼 데이터가 삭제되는 작업은 실행하기 전에 한 번 더 확인을 받는다.|NEEDS_07, NEEDS_09|User-006, Admin-003, Wish-003|
|사용성|UI-004|조회 결과 없음 안내|위시리스트, 구매완료 목록, 회원 목록에 조회할 결과가 없으면 비어 있다는 것을 안내한다.|NEEDS_03, NEEDS_08|Wish-004, Wish-007, Admin-001|
|사용성|UI-005|기본 이미지 표시|물건의 이미지가 없으면 기본 이미지를 보여 준다.|NEEDS_05|Wish-004, Wish-009|
|사용성|UI-006|링크 자동 입력 실패 시 직접 입력|쇼핑몰 링크로 물건 정보를 자동으로 채우지 못하면 이름, 가격, 이미지를 회원이 직접 입력할 수 있다. 실패했다는 사실도 함께 안내한다.|NEEDS_05|Wish-009|
