# 요구사항명세 - 기능 작성

- 근거 문서 : [requirements-list.md](./requirements-list.md) (User-, Wish-, Admin-, Data-, Sec-, Sys-, UI-)
- 관련 이슈 : #5
- 현재 버전 : v0.1
- 변경 내용 : v0.1 - 기능 요구사항 상세내용 작성

## 1. 사용자

|요구사항분류|요구사항 ID|요구사항명|요구사항 상세|근거|사용 주체|
|--|--|--|--|--|--|
|사용자|User-001|회원가입|비회원이 회원 아이디, 비밀번호, 회원 이름, 이메일 주소를 입력해 회원으로 가입한다. 회원 아이디는 영문 대/소문자, 숫자로 20자 이하여야 한다. 비밀번호는 영문, 숫자, 특수문자(`! @ # $ % ^ & *`) 중 2종류 이상을 조합하면 10자 이상, 3종류 이상을 조합하면 8자 이상이어야 하고 연속된 숫자는 사용할 수 없다. 이메일 주소에는 @가 들어 있어야 한다. 가입 후에는 로그인하여 자신의 위시리스트를 사용할 수 있다.|C1, NEEDS_02|비회원|
|사용자|User-002|로그인|회원이 가입한 아이디와 비밀번호로 로그인한다. 로그인해야 위시리스트와 내 정보 화면을 사용할 수 있다. 관리자는 DB를 생성할 때 미리 만들어 둔 관리자 계정으로 회원과 같은 로그인 화면에서 로그인한다. 로그인하면 회원은 회원 메뉴(위시리스트 메뉴)로, 관리자는 관리자 메뉴로 이동한다.|C1, NEEDS_02|회원, 관리자|
|사용자|User-003|로그아웃|로그인한 회원이 로그아웃한다. 로그아웃하면 위시리스트와 내 정보 화면에 접근할 수 없다.|C1|회원, 관리자|
|사용자|User-004|내 정보 확인|회원이 자신의 회원 아이디, 회원 이름, 이메일 주소를 확인한다. 다른 회원의 정보는 볼 수 없다.|NEEDS_07|회원|
|사용자|User-005|내 정보 수정|회원이 자신의 회원 아이디를 제외한 모든 회원 정보를 수정할 수 있다. 비밀번호를 바꿀 때는 기존 비밀번호와 새 비밀번호를 함께 입력하고, 기존 비밀번호가 맞을 때만 변경할 수 있다. 새 비밀번호는 회원가입의 비밀번호 규칙을 따른다.|NEEDS_07|회원|
|사용자|User-006|회원 탈퇴|회원이 원할 때 탈퇴한다. 탈퇴 전에 한 번 더 확인을 받고(UI-003), 비밀번호는 다시 입력받지 않는다. 관리자 계정은 탈퇴할 수 없다. 탈퇴하면 해당 회원의 정보와 위시리스트 데이터를 완전히 삭제한다(Data-003).|NEEDS_07|회원|

## 2. 위시관리

|요구사항분류|요구사항 ID|요구사항명|요구사항 상세|근거|사용 주체|
|--|--|--|--|--|--|
|위시관리|Wish-001|물건 등록|회원이 물건의 이름, 가격, 우선도를 입력해 위시리스트에 등록한다. 우선도는 '높음 / 보통 / 낮음' 중에서 선택한다. 물건 이름, 가격, 우선도는 필수로 입력하며, 쇼핑몰 링크와 이미지 파일(.jpg, .png, .gif)은 선택으로 등록할 수 있다. 물건 이름은 200자 이하, 가격은 0원 이상이어야 한다(출시 예정이나 가격 미정인 물건을 위해 0원을 허용한다). 구매 여부는 '구매안함'이 기본으로 설정된다. 입력값은 형식을 검증한다(Sec-005).|NEEDS_01, C2|회원|
|위시관리|Wish-002|물건 수정|회원이 등록한 물건의 이름, 가격, 우선도를 수정한다. 본인이 등록한 물건만 수정할 수 있다(Sec-001). 물건 이름은 200자 이하, 가격은 0원 이상이어야 한다. 구매완료된 물건은 수정할 수 없다.|NEEDS_01|회원|
|위시관리|Wish-003|물건 삭제|회원이 등록한 물건을 삭제한다. 본인이 등록한 물건만 삭제할 수 있다(Sec-001). 구매완료된 물건도 삭제할 수 있다. 삭제하기 전에 한 번 더 확인을 받는다.|NEEDS_01|회원|
|위시관리|Wish-004|위시리스트 조회|회원이 자신이 등록한 물건 중 구매안함 상태인 물건을 목록으로 확인한다. 구매완료한 물건은 목록에서 숨겨지고 구매완료 탭에서 확인한다(Wish-007). 목록에는 물건의 이름, 가격, 우선도가 표시된다. 목록에서 물건을 누르면 상세 정보로 물건의 이미지와 등록일을 추가로 확인할 수 있고, 저장된 쇼핑몰 링크가 있으면 링크를 눌러 해당 쇼핑몰로 이동할 수 있다. 기본 정렬은 등록일 기준으로 최근에 등록한 물건이 가장 위에 온다. 다른 회원의 물건은 보이지 않는다(Sec-001). 등록한 물건이 없으면 없다는 안내를 보여 준다(UI-004).|NEEDS_01, NEEDS_02, C2|회원|
|위시관리|Wish-005|우선도순 조회|회원이 위시리스트(구매안함 물건)를 우선도가 높은 순으로 확인한다. 우선도가 같은 물건은 가격이 높은 물건이 위로 오도록 정렬하고, 가격도 같으면 먼저 등록한(오래된) 물건이 위로 오도록 정렬한다.|NEEDS_04|회원|
|위시관리|Wish-006|구매완료 표시|회원이 구매한 물건에 구매완료 표시를 한다. 표시한 물건은 위시리스트 목록에서 사라지고 구매완료 탭에 모아진다. 구매 날짜는 기록하지 않는다. 구매완료 표시는 취소할 수 있고, 취소하면 다시 위시리스트 목록에 표시된다.|NEEDS_03, C2|회원|
|위시관리|Wish-007|구매완료 목록 조회|회원이 구매완료로 표시한 물건만 구매완료 탭에서 따로 모아 확인한다. 구매완료한 물건이 없으면 없다는 안내를 보여 준다(UI-004).|NEEDS_03|회원|
|위시관리|Wish-008|총 필요 금액 확인|회원이 위시리스트에서 앞으로 결제해야 할 총 금액을 확인한다. 이미 구매완료한 물건은 총 금액에 포함하지 않는다.|NEEDS_06|회원|
|위시관리|Wish-009|쇼핑몰 링크 자동 입력|회원이 쇼핑몰 링크를 등록하면 물건의 이미지, 이름, 가격이 자동으로 채워진다. 자동 입력을 지원하는 쇼핑몰은 네이버, 11번가이며 입력한 링크는 저장한다. 자동으로 채워진 내용은 등록 전에 회원이 확인하고 수정할 수 있다. 자동 입력이 실패하면 회원이 직접 입력할 수 있고(UI-006), 이미지가 없으면 기본 이미지를 보여 준다(UI-005).|NEEDS_05|회원|

## 3. 관리자

|요구사항분류|요구사항 ID|요구사항명|요구사항 상세|근거|사용 주체|
|--|--|--|--|--|--|
|관리자|Admin-001|회원 목록 조회|관리자가 가입한 회원의 목록을 확인한다. 목록에는 회원 아이디, 회원명, 이메일 주소가 표시되며 관리자 계정은 포함하지 않는다. 관리자만 사용할 수 있다(Sec-003). 조회 결과가 없으면 없다는 안내를 보여 준다(UI-004).|NEEDS_08|관리자|
|관리자|Admin-002|회원 상세 정보 조회|관리자가 목록에서 선택한 회원의 상세 정보를 확인한다. 관리자만 사용할 수 있다(Sec-003). 관리자는 회원의 위시리스트를 확인할 수 없다.|NEEDS_08|관리자|
|관리자|Admin-003|회원 탈퇴 처리|관리자가 문제가 있는 회원을 탈퇴 처리한다. 관리자만 사용할 수 있다(Sec-003). 처리 전에 한 번 더 확인을 받는다. 탈퇴 사유는 입력하지 않는다. 관리자 계정은 탈퇴 처리할 수 없다. 탈퇴 처리된 회원의 정보와 위시리스트 데이터는 완전히 삭제한다.|NEEDS_09|관리자|
