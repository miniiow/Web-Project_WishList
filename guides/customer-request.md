# 고객 요청사항 - 위시리스트 관리
- 제공자 : 개발자(고객 역할)
- 원 요청일 : 2026-11-08
- ID 표기 : NEEDS_01 ~ NEEDS_09
- 사용자 : 위시리스트를 관리하는 회원, 회원을 관리하는 관리자

## 고객이 해결하고 싶은 문제
>사고 싶은 물건을 카카오톡 나와의 채팅이나 쇼핑몰마다 다른 장바구니에 넣어 두다 보니, 무엇이 가장 필요한지와 비용이 얼마나 필요한지 헷갈립니다. 사고 싶은 물건과 가격, 우선도를 한곳에서 확인하고 무엇부터 살지 정하는 데 참고할 수 있으면 좋겠습니다.
 

## 고객 요청
|ID|고객 요청|
|--|--|
|NEEDS_01|사고 싶은 물건의 이름, 가격, 우선도를 한곳에 적고, 바뀌면 수정하거나 삭제할 수 있었으면 좋겠습니다.|
|NEEDS_02|내 위시리스트는 나만 볼 수 있었으면 좋겠습니다.|
|NEEDS_03|구매한 물건은 구매완료 표시를 하고, 따로 확인할 수 있었으면 좋겠습니다.|
|NEEDS_04|물건의 우선도가 높은 순으로 확인할 수 있었으면 좋겠습니다.|
|NEEDS_05|원하는 물건의 쇼핑몰 링크를 등록하면 자동으로 물건의 이미지와 이름, 가격이 채워졌으면 좋겠습니다.|
|NEEDS_06|위시리스트에 있는 모든 물건을 전부 구매하면 얼마나 필요한지 알 수 있었으면 좋겠습니다.|
|NEEDS_07|내 정보를 확인하거나 수정하고, 원한다면 탈퇴할 수 있었으면 좋겠습니다.|
|NEEDS_08|가입한 회원들의 목록과 정보를 확인할 수 있었으면 좋겠습니다.|
|NEEDS_09|문제가 있는 회원은 탈퇴 처리할 수 있었으면 좋겠습니다.|

## 공통 개발 조건
|ID|조건|
|--|--|
|C1|회원마다 자신의 위시리스트를 따로 관리하는 MVC 기반 웹 프로그램을 목표로 합니다.|
|C2|핵심 목표는 물건 추가, 위시리스트 확인, 구매 완료 처리입니다.|
|C3|JSP, Servlet 기반 동적 화면으로 구성합니다. 특정 프레임워크나 버튼 배치를 지금 필수로 정하지 않습니다.|
|C4|쇼핑몰 계정의 연동, 장바구니 자동 가져오기, 실제 구매 여부 자동 확인, 월별 예산 관리는 제외합니다.|
